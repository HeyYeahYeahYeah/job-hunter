# job-hunter

输入一个专业名称，自动从主流招聘网站（以智联招聘为主）抓取该专业近两年可申报的岗位（约 30~50 个），重点分析岗位所需能力，反推课程标准修订建议，生成结构化分析报告。

## 功能

- 输入「专业名 + 学历（默认大专）」，自动生成一组对口搜索关键词
- 抓取岗位字段：岗位名称、公司、薪资、城市、经验、学历、技能关键词、链接
- **能力需求分析**（核心）：从岗位技能词提取能力，聚类成能力大类，统计频次排名
- **能力 → 课程映射**：把能力大类映射为建议课程/实训项目
- **岗位 × 能力对照**：每个岗位具体需要哪些能力
- **课程标准修订建议**：按能力频次排序，输出应强化的核心能力模块 + 修订原则
- 学历过滤：默认只要「大专」可投岗位（含「学历不限/大专可投」）
- 双格式交付：`<专业>岗位分析报告.md` + `<专业>岗位明细.xlsx`

## 用法

对话中直接触发，例如：

> 帮我看看智能控制专业（大专）能找什么工作

> 分析一下自动化专业的大专对口岗位

## 目录结构

```
job-hunter/
├── SKILL.md               # 工作流、抓取策略、能力分析规范、已知限制
└── scripts/
    └── analyze.py         # 读 jobs_raw.json → 生成 Markdown 报告 + Excel 明细
```

## 依赖

- `openpyxl`（缺失时 `pip install openpyxl`）

## 脚本调用

```
python analyze.py <jobs_raw.json> [专业名] [输出目录] [学历:默认大专]
```

## 已知限制

- BOSS直聘、猎聘对未登录/自动化访问风控较严，可能需人工辅助或降级。
- 智联招聘对未登录用户统一遮挡薪资数字（显示「查看薪资」/「面议」），抓到的岗位薪资多为面议；如需薪资区间，可结合 BOSS直聘（薪资公开但需登录）或用户手工登录后抓取。
- 实际可稳定抓取的数据源以智联招聘为主（WebFetch 可解析完整岗位详情）；51job/猎聘的搜索列表多为 JS 动态渲染，WebFetch 只能拿到 SEO 导航页。
- 「近两年」依赖站点能按时间筛选；部分站点默认按相关性排序，需在结果中核对发布时间。

## 待接入

用户如有现成的课程标准文件（如某门课的课程标准.docx），可把岗位能力清单与课标「课程目标/能力要求」逐条对照，标出「已覆盖 / 未覆盖 / 需强化」，直接产出课程标准修订清单。
